# ADR 0004: External Integration Deferred

- Status: Accepted
- Date: 2026-08-05

MAAW is a biblical-theological research workbench and is not related to
political-pathology work. It may reuse similar tooling patterns, but no
external repository receives or coordinates its findings by default.

Any future export must be introduced through a separate issue and must document
the receiving system, source-rights boundary, review gate, and promotion rules.
