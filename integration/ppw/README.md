# Political Pathology Workbench Integration

MAAW is intended to register in PPW as a **comparative evidence module**.

## Ownership boundary

MAAW owns agency-attribution hypotheses, agent/mechanism/medium distinctions,
argument graphs, rival explanations, attribution adjudication, tradition-lens
comparison, and reviewed export candidates.

PPW owns parent case and theory coordination, promoted claims and
interpretations, scores, theory evaluation, and cross-module publication.

## Export rule

`npm run export:ppw` writes a generated bundle to
`integration/ppw/generated/`. It contains only findings explicitly reviewed by
a human. Draft findings remain local.
